Bett Leveling Kalibrierung
Benötigt: Nichts

Diese Kalibrierung ist die erste, die durchgeführt werden sollte, da sie notwendig ist, damit ein Druck gut auf dem Druckbett haftet.

Diese Kalibrierung dient der Feinabstimmung. Bitte leveln Sie den Drucker vor dem Start grob und bewegen Sie die Düse auf 0,2 mm über das Druckbett. Ein Blatt Papier sollte sich zwischen Düse und Bett bewegen lassen, wobei Sie die Düse dabei leicht spüren sollten. Danach sollten Sie das Bett mit einer Genauigkeit von etwa 0,1 mm leveln können.

So funktioniert es

Wählen Sie zuerst Ihren Drucker und Ihr Standard Druckprofil mit dem Filamentprofil für das verwendete Filament aus. Beachten Sie, dass diese Kalibrierung bei mehreren Extrudern nur mit dem ersten Extruder funktioniert.

Wenn Sie auf die Schaltfläche "Generieren" klicken, erstellt und sliced das Programm den Testdruck. Sie müssen ihn anschließend an Ihren Drucker senden und ausdrucken. Nach dem Druck vergleichen Sie die fünf Felder mit den Fotos unten. Falls nötig, müssen Sie Ihren Drucker oder die Firmware anpassen, um die Höhe zu korrigieren.

Lesen Sie für weitere Informationen auch die Hinweise und Empfehlungen unten.

So stellen Sie Ihren Drucker ein

Wenn Ihr Drucker Bettschrauben hat, verwenden Sie diese, um das Bett an der Stelle des betreffenden Feldes anzuheben oder abzusenken. Vergessen Sie nicht, den Test nach der Anpassung erneut zu drucken, um die Korrektur zu prüfen. Seien Sie vorsichtig: Häufig entspricht bereits eine halbe Umdrehung etwa 0,2 mm Höhenänderung, was in etwa der Höhe der ersten Schicht entspricht. Wenn Sie das Bett anheben, drehen Sie nie mehr als das und meist höchstens eine Vierteldrehung.

Wenn Ihr Drucker keine Bettschrauben hat, müssen Sie die Software oder die Firmware Konfiguration verwenden. Beachten Sie dazu das Handbuch Ihres Druckers.

Empfehlungen

Wenn Ihr Filament schlecht auf dem Bett haftet, können Sie Folgendes versuchen:

  • Erhöhen Sie die Breite der ersten Schicht. Das erhöht den Anpressdruck ohne Überextrusion. Sie können bis auf 200% der Düsenbreite gehen, meist reichen aber 150%. (Erweiterte Einstellung, Druck -> Breite)
  • Verringern Sie die Druckgeschwindigkeit der ersten Schicht, damit das Material mehr Zeit zum Haften hat. (Erweiterte Einstellung, Druck -> Geschwindigkeit)
  • Sie können Z Hop für die erste Schicht deaktivieren oder aktivieren, indem Sie "only lift z" -> "above Z" höher als die Höhe Ihrer ersten Schicht setzen. Aktiviert kann das Filament vom Bett abgezogen werden, deaktiviert kann die Düse das Bett berühren und das abgelegte Filament verschieben. Hier müssen Sie den optimalen Wert testen. (Erweiterte Einstellung, Drucker -> Extruder)

Hinweise

Dieser Test verwendet Ihre aktuelle Höhe der ersten Schicht. Falls Sie Ihr Bett zum ersten Mal leveln, sollten Sie den Wert vor dem Generieren eventuell auf bis zu 80% Ihrer Düsenhöhe erhöhen, um das Risiko eines Düsencrashs zu verringern.

Wenn sich nach der Filamentfluss Kalibrierung zeigt, dass der Fluss stark falsch eingestellt war, sollten Sie diese Kalibrierung später eventuell erneut durchführen.

Die meisten Kalibrierungen sollten in der richtigen Reihenfolge durchgeführt werden. Diese hier ist die erste. Wenn Sie gute Ergebnisse erzielen möchten, sollten Sie außerdem Ihren Extruder kalibrieren. Wenn Sie ihn zum Beispiel 100 mm Filament extrudieren lassen, sollte genau diese Länge auch wirklich in die Düse gefördert werden.

Dieser Test setzt die Einstellung "Komplette einzelne Objekte" auf aktiv. Möglicherweise möchten Sie Ihre Druckeinstellungen danach wieder zurücksetzen.
